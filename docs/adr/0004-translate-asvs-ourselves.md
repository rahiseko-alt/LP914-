# ASVS の日本語は、外部の訳に頼らず自分で訳して原文を併記する

ASVS 5.0.0 の日本語訳は `owasp-ja/asvs-ja` に存在するが、README 自身がドラフトと明記して
おり、OWASP 本体の 5.0.0 配布言語にも日本語は含まれていない（en / fr / id / ko / pt / ru /
tr のみ）。固定表は「変わらないこと」そのものが価値なので、更新も番号体系も他者の手にある
ドラフトに依存させない。原文から訳し、**各項目に原文をそのまま併記**して、訳が疑わしい
ときは原文で確かめられるようにする。

## Consequences

- 訳の誤りはこの置き場所の責任になる。原文を併記しているため、読み手が気づける。
- ASVS のライセンス（CC BY-SA 4.0）は翻訳と再配布を許すが、**出典の明記が必要**。
  `docs/safety-check/README.md` に記載した。
- `owasp-ja/asvs-ja` が正式版になった場合は、訳語の照合に使ってよい。ただし固定表の
  項目 ID と原文は、同梱した公式データ（`docs/safety-check/asvs-5.0.0-l1.csv`）を正とする。
