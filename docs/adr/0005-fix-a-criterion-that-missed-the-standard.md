# 合格基準が標準を写し取れていなかったときは、基準を直して判定し直す

7.4.1（ログアウト後は一切使えなくする）の合格基準を「サーバ側で通らなくなること」とだけ
書いていた。ASVS の原文は、取り消せない引換券を使う場合に無効一覧などの手当てを明示して
求めているのに、その部分を日本語の基準が落としていた。結果、**サーバ側のログイン状態が
消えることだけを見て合格**とし、発行済みの引換券が最大1時間通り続ける穴を見逃した。
基準を原文に合わせて直し、判定をやり直した（合格 → 不合格）。

## Consequences

- **基準は判定の途中では変えない。** その場で緩めたり厳しくしたりすれば、判定ではなく
  その場の判断になる。変えてよいのは、基準が**標準を写し取れていないと分かったとき**だけで、
  変更は固定表に書き、理由をここに残し、影響を受ける項目を**すべて判定し直す**。
- 判定が合格から不合格に変わることを、変更を避ける理由にしない。標準に合っていない基準で
  出した合格は、最初から合格ではない。
- 同じ取りこぼしを防ぐため、`読む` の項目の合格基準を書くときは、**原文が「〜の場合は
  こうする」と条件付きで求めている部分を落としていないか**を確かめる。
