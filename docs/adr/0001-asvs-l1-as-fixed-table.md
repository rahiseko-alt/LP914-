# 安全確認の土台に OWASP ASVS 5.0.0 の L1 を採用する

AI に安全確認をさせると、見つけるたびに項目が増えて終わらない。原因は検査の量ではなく、
「何を全部満たせば終わりか」を事前に確定した一覧が無いことだった。そこで新しい検査道具は作らず、
既に公式に確定している OWASP ASVS 5.0.0（345項目・番号固定・CSV/JSON 配布・CC BY-SA 4.0）を
固定表の土台とし、まず L1 の70項目を全件対象とする。

## Considered Options

- **OWASP WSTG（113項目）**: 攻撃者視点の検査手順であり、非エンジニアが自分で実行できない。
- **IPA「安全なウェブサイトの作り方」チェックリスト（47項目）**: 日本語で最も読みやすいが 2021年版で、
  BaaS の行単位アクセス制御・クラウドの設定ミス・鍵の流出を扱っていない。補助解説としてのみ使う。
- **Vercel / Firebase の公式チェックリスト**: 番号が無く随時改訂されるため「事前に確定」を満たさない。
- **OWASP Top 10 / Proactive Controls（各10項目）**: 粗すぎて項目単位の判定に使えない。

## Consequences

ASVS には「機械で自動判定できる項目／人が読むしかない項目」の公式区分が無い。
この区分は自前で定義する必要がある。
