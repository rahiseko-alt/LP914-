## V12 安全な通信（3項目）

### v5.0.0-12.2.1 — 暗号化されない通信に落ちないか

**判定: 不合格**

この項目の命令は**備えを探す命令**である。暗号化なしで取りに行った結果が **200 で、中身が
そのまま返った**。転送先の指定も無い。

```
$ curl -sS -I --max-time 30 http://trimmer-system.kouheikosehira.com
HTTP/1.1 200 OK
content-type: text/html; charset=utf-8
（location の行は無い）

$ curl -sS --max-time 30 http://trimmer-system.kouheikosehira.com | head -3
<!DOCTYPE html>
<html lang="ja">
<head>
```

`/api/ping` でも同じく 200 が返った。合格基準は「301 か 308 で `https://` へ送る」か
「中身を返さない」のどちらかを求めており、どちらでもない。

**何が起きうるか**: 利用者が `https://` を付けずにアドレスを打った、あるいは暗号化されて
いないリンクを踏んだとき、**そのまま暗号化されない通信でやり取りが始まる**。店や自宅以外の
無線（カフェ、コワーキング、ホテル）を使っていると、間に入った相手に**画面の中身も、
ログイン引換券も、そのまま見える**。引換券を取られれば、その人になりすまして**カルテを
読める**。

3.4.1（暗号化を強制する見出しが無い）と合わせると、**割り込まれたまま気づけない**状態に
なる。この2件は同じ設定で同時に直る。

**どうすると直るか**: Cloudflare の設定で「Always Use HTTPS」を有効にする
（SSL/TLS → Edge Certificates）。暗号化なしで来た要求を、自動で暗号化された側へ送り返す。
同じ画面にある「HSTS」を合わせて有効にすれば 3.4.1 も同時に直る。**この2つは、コードを
1行も変えずに設定だけで直る。判断は対象アプリの持ち主に委ねる。**

### v5.0.0-12.1.1 — 通信の暗号化に新しい版だけを使っているか

**判定: 判定不能**

最低の版がいくつに設定されているかを、こちらから確かめられなかった。手元の道具が古い版
（TLS 1.0 / 1.1）を扱えないため、**拒まれたのか、こちらから送れなかったのかを区別できない**。

```
$ curl --tlsv1.0 --tls-max 1.1 https://trimmer-system.kouheikosehira.com
curl: (35) OpenSSL/3.0.13: error:0A0000BF:SSL routines::no protocols available
```

合格基準は「手元から古い版で繋がらなかったことだけを根拠に合格としない」と定めている。
そのとおり、判定不能とした。

**次にやること**: Cloudflare の SSL/TLS → Edge Certificates にある
「Minimum TLS Version」を1枚見て、記録に書く。TLS 1.2 以上なら合格になる。
