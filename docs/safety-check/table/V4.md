# 固定表 — V4 API と Web サービス（API and Web Service）

OWASP ASVS 5.0.0 の L1 のうち、この章に属する **2項目**。項目は公式データ
（`../asvs-5.0.0-l1.csv`）と1対1で対応し、追加・削除・統合をしない。

判定のしかたは `機械`（実行する命令が確定しているもの）か `読む`（見る場所が確定している
もの）のどちらか。どちらの命令も、**対象アプリの置き場所の最上位で `bash` で実行する**。

出典: OWASP Application Security Verification Standard 5.0.0 (CC BY-SA 4.0)。
日本語は原文からの訳で、訳の責任はこの置き場所にある（`../../adr/0004` 参照）。

## この章の共通の但し書き

- **命令には3つの種類があり、出力が0件のときの意味が逆になる。** どれに当たるかを各項目の
  「命令の種類」に書く。書いていない命令は使わない。
  - **危険な書き方を探す命令**: 0件なら**合格**。探した書き方をしていない、という意味になる
  - **備えを探す命令**: 0件なら**不合格**。在るべきものが無い、という意味になる
  - **対象の一覧を作る命令**: 0件なら**判定不能**。対象が無いのか、命令が対象アプリの書き方と
    合っていないのかを区別できないため（`../../adr/0002`・`../../adr/0006`）
- **命令の出力に紛らわしい行が出たときは、その行を読む。** 本番の画面から到達できない
  試験専用の道具だと確かめられた場合に限り、その行を数に入れない。確かめられなければ
  数に入れる。**読まずに除外しない。読んだ行はすべて、確かめた結果とともに判定結果に残す。
  出力の一部を無記録で落とさない。**
- **命令は対象アプリの置き場所の最上位で `bash` で実行し、表に書いたとおりに実行する。**
  省略や追加をしない。探す範囲に対象アプリ固有の置き場所の名前を書かない。失敗を
  `2>/dev/null` で隠さない（隠すと、別のアプリに当てたとき黙って0件＝合格になる）。

### v5.0.0-4.1.1

- **原文**: Verify that every HTTP response with a message body contains a Content-Type header field that matches the actual content of the response, including the charset parameter to specify safe character encoding (e.g., UTF-8, ISO-8859-1) according to IANA Media Types, such as "text/", "/+xml" and "/xml".
- **日本語**: 中身のある応答すべてに、その中身に合った種類の見出し（Content-Type）を付けること。文字の並べ方（charset）も指定すること。
- **判定のしかた**: 読む
- **見る場所**: 次の命令の出力に挙がった箇所と、公開されている画面から実際に取った応答の見出し。ここに挙がらない場所は見ない。

  ```
  grep -rnoiE "content-type|charset" --include='*.js' --include='*.mjs' . | grep -v node_modules
  curl -sS -I --max-time 30 https://<ホスト名>
  ```

- **合格基準**: 中身を返す経路すべてが、中身に合った種類の見出しを付けており、**文字の並べ方も指定している**こと。指定の無い経路が1つでもあれば不合格。
- **該当しない条件**: 無い。
- **根拠として出すもの**: 種類を決めている箇所のファイル名と行番号と、実際に取った応答の該当行。

### v5.0.0-4.4.1

- **原文**: Verify that WebSocket over TLS (WSS) is used for all WebSocket connections.
- **日本語**: 双方向の通信（WebSocket）を使う場合、暗号化された形（WSS）だけを使うこと。
- **判定のしかた**: 機械
- **命令の種類**: 危険な書き方を探す命令
- **合格基準**: 次の命令の出力が**0件**であること。1件でも出れば不合格（暗号化されていない双方向の通信を使っている）。

  ```
  grep -rnoiE "ws://" --include='*.js' --include='*.mjs' --include='*.html' . | grep -v node_modules
  ```

- **該当しない条件**: 双方向の通信を使っていない場合（`WebSocket` `socket.io` の出現が、本番の画面に載る箇所に1つも無い場合）。このときは「合格（該当機能なし）」とする。
- **根拠として出すもの**: 命令の出力そのものと、双方向の通信を使っていないことを示す出力。
