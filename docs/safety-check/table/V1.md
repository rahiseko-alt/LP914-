# 固定表 — V1 符号化とサニタイズ（Encoding and Sanitization）

OWASP ASVS 5.0.0 の L1 のうち、章 V1 に属する **8項目**。項目は公式データ
（`../asvs-5.0.0-l1.csv`）と1対1で対応し、追加・削除・統合をしない。

判定のしかたは `機械`（実行する命令が確定しているもの）か `読む`（見る場所が確定している
もの）のどちらか。どちらの命令も、**対象アプリの置き場所の最上位で `bash` で実行する**。

出典: OWASP Application Security Verification Standard 5.0.0 (CC BY-SA 4.0)。
日本語は原文からの訳で、訳の責任はこの置き場所にある（`../../adr/0004` 参照）。

## この章の共通の但し書き

- **命令が何も見つけられなかったときは、合格ではなく判定不能とする**（`../../adr/0002`）。
- **命令の出力に紛らわしい行が出たときは、その行を読む。** 本番の画面から到達できない
  試験専用の道具だと確かめられた場合に限り、その行を数に入れない。確かめられなければ
  数に入れる。**読まずに除外しない。**確かめた根拠を判定結果に残す。

【画面を組み立てる書き方を調べる命令】

```
grep -rnoE 'innerHTML|outerHTML|insertAdjacentHTML|document\.write' --include='*.js' --include='*.mjs' --include='*.html' . | grep -v node_modules
```

### v5.0.0-1.2.1

- **原文**: Verify that output encoding for an HTTP response, HTML document, or XML document is relevant for the context required, such as encoding the relevant characters for HTML elements, HTML attributes, HTML comments, CSS, or HTTP header fields, to avoid changing the message or document structure.
- **日本語**: 画面や応答に値を埋め込むとき、埋め込む場所に応じて適切に変換すること。文書の構造が変わってしまわないようにするため。
- **判定のしかた**: 読む
- **見る場所**: 【画面を組み立てる書き方を調べる命令】の出力に挙がった箇所。ここに挙がらない場所は見ない。
- **合格基準**: 出力に挙がった箇所を1つずつ読み、**利用者が入力した値が、変換されないまま画面の組み立てに混ざっている箇所が0件**であること。1件でもあれば不合格。値が固定の文字列だけで組み立てられ、利用者の値は `textContent` などの安全な入れ方で入っている場合は合格。
- **該当しない条件**: 無い。
- **根拠として出すもの**: 挙がった箇所それぞれについて、ファイル名と行番号、および読んだ結果（固定の文字列か、利用者の値か）。

### v5.0.0-1.2.2

- **原文**: Verify that when dynamically building URLs, untrusted data is encoded according to its context (e.g., URL encoding or base64url encoding for query or path parameters). Ensure that only safe URL protocols are permitted (e.g., disallow javascript: or data:).
- **日本語**: URL を組み立てるとき、信用できない値を場所に応じて変換すること。`javascript:` や `data:` のような危険な形式の URL を許さないこと。
- **判定のしかた**: 機械
- **合格基準**: 次の命令の出力が**0件**であること。1件でも出れば、その行を読んで判断し、利用者の値が URL の形式部分に入りうるなら不合格。

  ```
  grep -rnoE "(href|src|action) *= *[^=;]*(javascript:|data:text|data:application)" --include='*.js' --include='*.mjs' --include='*.html' . | grep -v node_modules
  ```

- **該当しない条件**: 無い。
- **根拠として出すもの**: 命令の出力そのもの。

### v5.0.0-1.2.3

- **原文**: Verify that output encoding or escaping is used when dynamically building JavaScript content (including JSON), to avoid changing the message or document structure (to avoid JavaScript and JSON injection).
- **日本語**: JavaScript や JSON を組み立てて画面に埋め込むとき、構造が変わらないように変換すること。
- **判定のしかた**: 読む
- **見る場所**: 次の命令の出力に挙がった箇所。

  ```
  grep -rnoE 'JSON\.stringify|<script|type="application/json"' --include='*.js' --include='*.mjs' --include='*.html' . | grep -v node_modules | head -30
  ```

- **合格基準**: 組み立てた JSON を画面の `<script>` の中に埋め込んでいる箇所がある場合、`</script` と行区切り記号（U+2028・U+2029）を変換していること。埋め込んでいる箇所が無ければ合格。
- **該当しない条件**: 無い。
- **根拠として出すもの**: 変換を行っている箇所のファイル名と行番号。埋め込みが無い場合はその旨と命令の出力。

### v5.0.0-1.2.4

- **原文**: Verify that data selection or database queries (e.g., SQL, HQL, NoSQL, Cypher) use parameterized queries, ORMs, entity frameworks, or are otherwise protected from SQL Injection and other database injection attacks. This is also relevant when writing stored procedures.
- **日本語**: データベースへの問い合わせを、値を差し込む形で組み立てないこと。文字列をつなげて命令文を作らないこと。
- **判定のしかた**: 機械
- **合格基準**: 次の命令の出力が**0件**であること。1件でも出れば、その行を読む。**命令文そのものを文字列でつないでいれば不合格**。つないでいるのが命令文ではなく値（パスや鍵の文字列など）であれば、その旨を根拠に記して合格としてよい。

  ```
  grep -rniE "execute +'|execute +format|execute +[a-z_]+ *\|\||query *\( *[\x27\x22][^\x27\x22]*\+" supabase/ worker/src/ backend/js/ 2>/dev/null
  ```

- **該当しない条件**: データベースを使っていない場合。
- **根拠として出すもの**: 命令の出力そのもの。出た行を読んだ場合はその判断も。

### v5.0.0-1.2.5

- **原文**: Verify that the application protects against OS command injection and that operating system calls use parameterized OS queries or use contextual command line output encoding.
- **日本語**: アプリが土台の機械に命令を出す箇所で、利用者の値がその命令に混ざらないようにすること。
- **判定のしかた**: 機械
- **合格基準**: 次の命令の出力が**0件**であること。出た場合は、その箇所に利用者の値が渡りうるかを読んで判断する。

  ```
  grep -rnoE 'child_process|execSync|spawnSync|\bexec\(|shelljs' --include='*.js' --include='*.mjs' worker/src/ backend/js/ src/ 2>/dev/null
  ```

- **該当しない条件**: アプリが土台の機械に命令を出さない作り（ブラウザとマネージドの仕組みだけで動く）である場合。このときは「合格（該当機能なし）」とする。
- **根拠として出すもの**: 命令の出力そのもの。

### v5.0.0-1.3.1

- **原文**: Verify that all untrusted HTML input from WYSIWYG editors or similar is sanitized using a well-known and secure HTML sanitization library or framework feature.
- **日本語**: 見たままに書ける編集画面などから受け取った HTML を、よく知られた安全な道具で無害化すること。
- **判定のしかた**: 読む
- **見る場所**: 次の命令の出力に挙がった箇所。

  ```
  grep -rnoE 'contenteditable|execCommand|DOMPurify|sanitize' --include='*.js' --include='*.mjs' --include='*.html' . | grep -v node_modules | head -20
  ```

- **合格基準**: 見たままに書ける編集画面がある場合、そこから受け取った内容を**HTML として保存・再表示していない**こと（文字として扱っている）か、無害化の道具を通していること。HTML として保存し、無害化もしていなければ不合格。
- **該当しない条件**: 見たままに書ける編集画面が無い場合。
- **根拠として出すもの**: 編集画面の箇所と、保存時に何を読んでいるか（文字か HTML か）のファイル名と行番号。

### v5.0.0-1.3.2

- **原文**: Verify that the application avoids the use of eval() or other dynamic code execution features such as Spring Expression Language (SpEL). Where there is no alternative, any user input being included must be sanitized before being executed.
- **日本語**: その場で文字列を命令として実行する仕組み（`eval` など）を使わないこと。
- **判定のしかた**: 機械
- **合格基準**: 次の命令の出力が**0件**であること。出た行は共通の但し書きに従って読み、本番の画面から到達できない試験専用の道具であれば数に入れない。

  ```
  grep -rnoE '\beval\(|new Function\(|setTimeout\( *[\x27\x22]|setInterval\( *[\x27\x22]' --include='*.js' --include='*.mjs' --include='*.html' . | grep -v node_modules
  ```

- **該当しない条件**: 無い。
- **根拠として出すもの**: 命令の出力そのもの。読んだ行についてはその判断も。

### v5.0.0-1.5.1

- **原文**: Verify that the application configures XML parsers to use a restrictive configuration and that unsafe features such as resolving external entities are disabled to prevent XML eXternal Entity (XXE) attacks.
- **日本語**: XML を読み込む仕組みを使う場合、外部のものを読みに行く機能を無効にすること。
- **判定のしかた**: 機械
- **合格基準**: 次の命令の出力が**0件**であること。出た場合は、その箇所が信用できない XML を読んでいるかを読んで判断する。

  ```
  grep -rnoE 'DOMParser|parseFromString|libxml|xml2js|fast-xml-parser|SAXParser' --include='*.js' --include='*.mjs' --include='*.json' . | grep -v node_modules
  ```

- **該当しない条件**: XML を読み込んでいない場合。このときは「合格（該当機能なし）」とする。
- **根拠として出すもの**: 命令の出力そのもの。
