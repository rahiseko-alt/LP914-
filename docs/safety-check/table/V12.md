# 固定表 — V12 安全な通信（Secure Communication）

OWASP ASVS 5.0.0 の L1 のうち、この章に属する **3項目**。項目は公式データ
（`../asvs-5.0.0-l1.csv`）と1対1で対応し、追加・削除・統合をしない。

判定のしかたは `機械`（実行する命令が確定しているもの）か `読む`（見る場所が確定している
もの）のどちらか。どちらの命令も、**対象アプリの置き場所の最上位で `bash` で実行する**。

出典: OWASP Application Security Verification Standard 5.0.0 (CC BY-SA 4.0)。
日本語は原文からの訳で、訳の責任はこの置き場所にある（`../../adr/0004` 参照）。

## この章の共通の但し書き

- **命令には3つの種類があり、出力が0件のときの意味が逆になる。** どれに当たるかを各項目の
  「命令の種類」に書く。書いていない命令は使わない。
  - **危険な書き方を探す命令**: 0件なら**合格**。探した書き方をしていない、という意味になる
  - **備えを探す命令**: 0件なら**不合格**。在るべきものが無い、という意味になる
  - **対象の一覧を作る命令**: 0件なら**判定不能**。対象が無いのか、命令が対象アプリの書き方と
    合っていないのかを区別できないため（`../../adr/0002`・`../../adr/0006`）
- **命令の出力に紛らわしい行が出たときは、その行を読む。** 本番の画面から到達できない
  試験専用の道具だと確かめられた場合に限り、その行を数に入れない。確かめられなければ
  数に入れる。**読まずに除外しない。読んだ行はすべて、確かめた結果とともに判定結果に残す。
  出力の一部を無記録で落とさない。**
- **命令は対象アプリの置き場所の最上位で `bash` で実行し、表に書いたとおりに実行する。**
  省略や追加をしない。探す範囲に対象アプリ固有の置き場所の名前を書かない。失敗を
  `2>/dev/null` で隠さない（隠すと、別のアプリに当てたとき黙って0件＝合格になる）。
【通信を実測する命令】（`<URL>` は対象アプリの入口。備えを探す命令）

```
curl -sS -o /dev/null -w 'https: code=%{http_code} 証明書の検証=%{ssl_verify_result}\n' --max-time 30 https://<ホスト名>
curl -sS -o /dev/null -w 'http: code=%{http_code} 転送先=%{redirect_url}\n' --max-time 30 http://<ホスト名>
```

対象アプリが公開されていない場合、この章の3項目はすべて**判定不能**とする。

### v5.0.0-12.1.1

- **原文**: Verify that only the latest recommended versions of the TLS protocol are enabled, such as TLS 1.2 and TLS 1.3. The latest version of the TLS protocol must be the preferred option.
- **日本語**: 通信の暗号化に、推奨されている新しい版（TLS 1.2 と 1.3）だけを使うこと。いちばん新しい版が優先されること。
- **判定のしかた**: 読む
- **見る場所**: 配信を担っている仕組みの設定画面のうち、通信の暗号化の最低の版を決めている箇所。手元からは古い版を試せないことがある（試す側の道具が古い版を扱えないと、拒まれたのか送れなかったのかを区別できない）。
- **合格基準**: 最低の版が **TLS 1.2 以上**に設定されていることが、設定画面または経緯の記録から分かること。分からなければ**判定不能**とする。手元から古い版で繋がらなかったことだけを根拠に合格としない。
- **該当しない条件**: 無い。
- **根拠として出すもの**: 設定値と、それを確かめた場所（画面の名前、または記録のファイル名と行番号）。

### v5.0.0-12.2.1

- **原文**: Verify that TLS is used for all connectivity between a client and external facing, HTTP-based services, and does not fall back to insecure or unencrypted communications.
- **日本語**: 利用者とやり取りするすべての通信を暗号化すること。暗号化されない通信に落ちないこと。
- **判定のしかた**: 機械
- **命令の種類**: 備えを探す命令
- **合格基準**: 【通信を実測する命令】の2行目（暗号化なしで取りに行く）について、次のどちらかであること。どちらでもなければ**不合格**。
  1. 応答が 301 か 308 で、転送先が `https://` で始まる
  2. 応答が 403 などで、中身が返らない

  **応答が 200 で中身が返る場合は不合格。** 暗号化されない通信でそのまま使える、という意味になる。
- **該当しない条件**: 無い。
- **根拠として出すもの**: 命令の出力の2行そのもの。200 が返った場合は、中身の先頭も。

### v5.0.0-12.2.2

- **原文**: Verify that external facing services use publicly trusted TLS certificates.
- **日本語**: 外向きの通信に、公に信頼されている証明書を使うこと。
- **判定のしかた**: 機械
- **命令の種類**: 備えを探す命令
- **合格基準**: 【通信を実測する命令】の1行目で、`証明書の検証` が **0**（検証できた）であること。0 以外なら不合格。
- **該当しない条件**: 無い。
- **根拠として出すもの**: 命令の出力の1行そのもの。
