# 固定表 — V15 安全なコーディングと構造（Secure Coding and Architecture）

OWASP ASVS 5.0.0 の L1 のうち、この章に属する **3項目**。項目は公式データ
（`../asvs-5.0.0-l1.csv`）と1対1で対応し、追加・削除・統合をしない。

判定のしかたは `機械`（実行する命令が確定しているもの）か `読む`（見る場所が確定している
もの）のどちらか。どちらの命令も、**対象アプリの置き場所の最上位で `bash` で実行する**。

出典: OWASP Application Security Verification Standard 5.0.0 (CC BY-SA 4.0)。
日本語は原文からの訳で、訳の責任はこの置き場所にある（`../../adr/0004` 参照）。

## この章の共通の但し書き

- **命令には3つの種類があり、出力が0件のときの意味が逆になる。** どれに当たるかを各項目の
  「命令の種類」に書く。書いていない命令は使わない。
  - **危険な書き方を探す命令**: 0件なら**合格**。探した書き方をしていない、という意味になる
  - **備えを探す命令**: 0件なら**不合格**。在るべきものが無い、という意味になる
  - **対象の一覧を作る命令**: 0件なら**判定不能**。対象が無いのか、命令が対象アプリの書き方と
    合っていないのかを区別できないため（`../../adr/0002`・`../../adr/0006`）
- **命令の出力に紛らわしい行が出たときは、その行を読む。** 本番の画面から到達できない
  試験専用の道具だと確かめられた場合に限り、その行を数に入れない。確かめられなければ
  数に入れる。**読まずに除外しない。読んだ行はすべて、確かめた結果とともに判定結果に残す。
  出力の一部を無記録で落とさない。**
- **命令は対象アプリの置き場所の最上位で `bash` で実行し、表に書いたとおりに実行する。**
  省略や追加をしない。探す範囲に対象アプリ固有の置き場所の名前を書かない。失敗を
  `2>/dev/null` で隠さない（隠すと、別のアプリに当てたとき黙って0件＝合格になる）。
【部品の一覧と更新の仕組みを調べる命令】（対象の一覧を作る命令）

```
ls package.json package-lock.json requirements.txt go.mod Gemfile; ls -a .github; grep -rlniE '依存|部品|更新|バージョン|脆弱|dependabot|npm audit|renovate' --include='*.md' --include='*.yml' . | grep -v node_modules
```

### v5.0.0-15.1.1

- **原文**: Verify that application documentation defines risk based remediation time frames for 3rd party component versions with vulnerabilities and for updating libraries in general, to minimize the risk from these components.
- **日本語**: 外から持ってきた部品に弱点が見つかったとき、どれくらいの期間で直すかを、危険の度合いに応じて文書に定めること。部品を普段どう更新するかも定めること。
- **判定のしかた**: 読む
- **見る場所**: 【部品の一覧と更新の仕組みを調べる命令】で挙がった文書と設定ファイル。ここに挙がらない場所は見ない。
- **合格基準**: 挙がった文書のどれかに、**弱点が見つかってから直すまでの期間**が、危険の度合いごとに書かれていること。「気づいたら直す」のような期間の定めがないものは不合格ではなく**判定不能**とする（記録が欠けている）。自動で更新を知らせる仕組みの設定があるだけでは、期間の定めにならない。
- **該当しない条件**: 外から持ってきた部品を1つも使っていない場合。
- **根拠として出すもの**: 該当箇所のファイル名と行番号。無い場合は、命令の出力そのもの。

### v5.0.0-15.2.1

- **原文**: Verify that the application only contains components which have not breached the documented update and remediation time frames.
- **日本語**: 文書に定めた更新・修正の期間を過ぎた部品が、含まれていないこと。
- **判定のしかた**: 読む
- **見る場所**: 15.1.1 で見つかった文書と、部品の一覧。
- **合格基準**: 15.1.1 が合格であり、かつ定めた期間を過ぎた部品が0件であること。**15.1.1 が判定不能なら、この項目も判定不能とする**（比べる相手が無いため）。
- **該当しない条件**: 外から持ってきた部品を1つも使っていない場合。
- **根拠として出すもの**: 期間の定めと、部品ごとの状態。ファイル名と行番号。

### v5.0.0-15.3.1

- **原文**: Verify that the application only returns the required subset of fields from a data object. For example, it should not return an entire data object, as some individual fields should not be accessible to users.
- **日本語**: データを返すとき、必要な項目だけを返すこと。まるごと返さないこと。
- **判定のしかた**: 読む
- **見る場所**: 次の命令の出力に挙がった箇所と、データを取り出している箇所。この2つ以外は見ない。
- **合格基準**: 次の2つをどちらも満たすこと。片方でも欠ければ不合格。
  1. 下の命令の出力のうち、**利用者に返す経路で使われているものが0件**であること
  2. データを取り出している箇所が、**項目を名前で並べている**こと

  ```
  grep -rnoE "select=\*|select\('\*'\)|SELECT \*" --include='*.js' --include='*.mjs' --include='*.sql' . | grep -v node_modules
  ```

- **該当しない条件**: 無い。
- **根拠として出すもの**: 命令の出力そのものと、項目を名前で並べている箇所のファイル名と行番号。
